# PainCube Demo

Investor-facing demo dashboard for PainCube, a predictive pain AI and AI-CDSS concept.

## Stack

- React
- Vite
- Tailwind CSS
- lucide-react

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Vercel settings:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
